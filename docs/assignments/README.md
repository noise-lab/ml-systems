# Assignments

The number of assignments varies by term (3–5 in a nine-week offering, 2 in the
three-week Paris offering); the term page linked from the [course page](../index.md)
says which ones are required and when they are due. Everything is submitted by
committing to your course repository.

## Required (typical)

| | Assignment | Repo |
|---|---|---|
| 1 | [Video Quality Inference](1-Video-Quality-Inference.html) — from pcap to a trained QoE model to a live Netflix session | [noise-courses/video-qoe](https://github.com/noise-courses/video-qoe) (rubric in `RUBRIC.md`) |
| 2 | Anomaly Detection — unsupervised detection on IoT and IDS traces | [noise-courses/anomaly-detection](https://github.com/noise-courses/anomaly-detection) |
| — | [Project](project.md) — proposal, then a runnable artifact and a report | [noise-courses/ml-sys-project](https://github.com/noise-courses/ml-sys-project) (proposal rubric in `proposal/RUBRIC.md`) |
